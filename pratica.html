Pegue o seu caderno e seu notbook e vamos começar a aprender!

a princípio aprendemos que tem 3 modos de aplicar o CSS:

Modos de Aplicar o CSS:

  • Modo Inline: Nesse modo, o CSS é aplicado diretamente na tag do HTML usando a tag style
  • Modo Internal: Nesse modo, o CSS é aplicado dentro da tag style no cabeçalho do documento HTML
  • Modo External: Nesse modo, o CSS é aplicado em um arquivo separado com a extensão .css e importado no documento HTML

Seletores no CSS:

Os seletores são utilizados para selecionar elementos HTML aos quais aplicar estilos CSS. Vamos aprender os 4 tipos de seletores:

  1. Seletores de Elemento: Selecionam elementos com base em seu nome (ex: h1, p, div)
  2. Seletores de Classe: Selecionam elementos com base em sua classe (ex: .classe)
  3. Seletores de ID: Selecionam elementos com base em seu ID (ex: #id)
  4. Seletores Universais: Selecionam todos os elementos (ex: *)

IMPORTANTE:As classes e IDs NÃO podem começar com números!!

Propriedades CSS:

As propriedades CSS são utilizadas para definir o estilo dos elementos HTML. Vamos aprender algumas das principais propriedades:

Propriedade Color Descrição
color Define a cor do texto do elemento selecionado
Propriedade Background Descrição
background É a propriedade que define todas as propriedades do background
background-color Define a cor de fundo do elemento selecionado
background-image Define uma imagem de fundo para o elemento selecionado
background-repeat Define se a imagem de fundo vai se repetir ou não
background-position Define a posição da imagem de fundo
background-size Define o tamanho da imagem de fundo
background-attachment Define se a imagem de fundo vai ficar fixa ou vai se mover junto com a rolagem da página
Propriedade Border Descrição
Border Define a borda do elemento selecionado
border-style Define o estilo da borda do elemento selecionado
border-color Define a cor da borda do elemento selecionado
border-radius Define se a borda do elemento selecionado vai ser arredondada ou não
border-top Define a borda superior do elemento selecionado
border-right Define a borda direita do elemento selecionado
border-bottom Define a borda inferior do elemento selecionado
border-left Define a borda esquerda do elemento selecionado
border Define a borda do elemento selecionado
Propriedade Margin Descrição
margin Define a margem do elemento selecionado
margin-top Define a margem superior do elemento selecionado
margin-right Define a margem direita do elemento selecionado
margin-bottom Define a margem inferior do elemento selecionado
margin-left Define a margem esquerda do elemento selecionado
Propriedade Padding Descrição
padding Define o espaçamento interno do elemento selecionado
Propriedade Width e Height Descrição
width Define a largura do elemento selecionado
height Define a altura do elemento selecionado
Propriedade Text Descrição
text-align Define o alinhamento do texto do elemento selecionado
text-decoration Define a decoração do texto do elemento selecionado
text-transform Define a transformação do texto do elemento selecionado
direction Define a direção do texto do elemento selecionado (ltr: da esquerda para a direita; rtl: da direita para a esquerda)
text-indent Define o recuo do primeiro caractere da linha do elemento selecionado
letter-spacing Define o espaçamento entre as letras do elemento selecionado
word-spacing Define o espaçamento entre as palavras do elemento selecionado
line-height Define a altura da linha do texto (o espaço entre as linhas) do elemento selecionado
Propriedade Font Descrição
font-family Define a família da fonte do elemento selecionado
font-size Define o tamanho da fonte do elemento selecionado
font-style Define o estilo da fonte do elemento selecionado
font-weight Define a espessura da fonte do elemento selecionado
Estilização de Links Descrição
a Define o estilo do link
a:link Define o estilo do link não visitado
a:visited Define o estilo do link já visitado
a:hover Define o estilo do link quando o mouse está sobre ele
a:active Define o estilo do link quando está sendo clicado
Propriedade Display Descrição
display Define como o elemento será exibido na página
display: block Define o elemento como um bloco, ocupando toda a largura disponível
display: inline Define o elemento como um elemento em linha, ocupando apenas a largura necessária
display: inline-block Define o elemento como um elemento em linha, mas permitindo definir largura e altura
obs: visibility: hidden; Funciona para que o elemento fique invisível, mas ainda ocupe espaço na página.
display: none; Funciona para que o elemento fique invisível, não ocupando espaço na página.
Max-width Descrição
max-width Define a largura máxima do elemento
Propriedade Position Descrição
position Define a posição do elemento na página
position: static Define o elemento como estático, seguindo o fluxo normal da página
position: relative Define o elemento como relativo, permitindo posicioná-lo em relação à sua posição original
position: absolute Define o elemento como absoluto, permitindo posicioná-lo em relação ao seu elemento pai mais próximo com posição relativa
position: fixed Define o elemento como fixo, permitindo posicioná-lo em relação à janela do navegador
position: sticky Define o elemento como fixo, permitindo posicioná-lo em relação à janela do navegador
Propriedade Overflow Descrição
overflow (Padrão) O conteúdo não é cortado e pode transbordar para fora da caixa do elemento.
overflow: hidden; O conteúdo que transborda é cortado (escondido), e nenhuma barra de rolagem é exibida
overflow: scroll; O conteúdo que transborda é cortado, mas barras de rolagem são sempre exibidas (horizontal e vertical), permitindo rolar o conteúdo.
overflow: auto; Similar ao 'scroll', mas as barras de rolagem aparecem apenas quando o conteúdo realmente transborda a caixa.
Propriedade Float Descrição
float Define se o elemento vai flutuar à esquerda ou à direita do seu contêiner pai.
float: left; O elemento flutua à esquerda do contêiner pai.
float: right; O elemento flutua à direita do contêiner pai.
float: none; (Padrão) O elemento não flutua. Ele aparece na ordem normal do documento.
float: inline-start; O elemento flutua para o início do bloco, dependendo da direção do texto (à esquerda para textos da esquerda para a direita, e à direita para textos da direita para a esquerda).
Propriedade Opacity Descrição
opacity Define a opacidade do elemento, variando de 0 (totalmente transparente) a 1 (totalmente opaco).
opacity: 0.5; Define o elemento com 50% de opacidade, tornando-o semi-transparente.
opacity: 1; Define o elemento como totalmente opaco, sem transparência.
opacity: 0; Define o elemento como totalmente transparente, tornando-o invisível.
Efeito Dropdown Descrição
dropdown Menu suspenso que aparece quando o usuário interage com um elemento (clicando ou passando o mouse). Muito usado em navegação, dá acesso a submenus ou opções extras sem ocupar espaço na interface principal.
gatilho Botão ou link que, ao receber a interação do usuário, faz o menu aparecer.
contêiner do menu Geralmente uma <div> que guarda os itens do menu e que será mostrada ou escondida.
.dropdown Elemento que envolve o gatilho e o menu. Usa position: relative e display: inline-block para servir de referência ao posicionamento do menu.
.dropdown-content O menu em si. Começa oculto (display: none;), usa position: absolute para aparecer por cima do conteúdo e z-index para ficar na frente dos outros elementos.
.dropdown:hover .dropdown-content Quando o mouse passa sobre o .dropdown, o menu é exibido (display: block;).
transições e animações Podem ser adicionadas para suavizar a aparição do menu.
Especificidade CSS Descrição
especificidade Determina qual regra será aplicada quando várias regras em conflito se aplicam ao mesmo elemento. Vence a regra com maior especificidade.
#id Seletores de ID têm peso 100. Ex: #menu → (1, 0, 0)
.classe, [atributo], :hover Seletores de classe, atributo e pseudo-classe (:hover, :focus) têm peso 10. Ex: .item → (0, 1, 0)
div, p, ::before Seletores de tag e pseudo-elementos (::before, ::after) têm peso 1. Ex: div → (0, 0, 1)
*, +, >, ~ O seletor universal e os combinadores não contam para a especificidade.
:not() A negação em si não conta, mas o seletor que está dentro dela conta normalmente.
(a, b, c) Forma de representar a especificidade: a = quantidade de IDs, b = classes, atributos e pseudo-classes, c = tags e pseudo-elementos.
Regra !important Descrição
!important Dá prioridade máxima a uma declaração, sobrescrevendo outras regras mesmo que tenham maior especificidade ou venham depois no código.
sintaxe É adicionado no final da declaração. Ex: color: red !important;
uso responsável O uso excessivo dificulta a manutenção do código e cria conflitos inesperados. Deve ser usado só quando necessário, como último recurso.
Efeito Gradiente Descrição
gradiente Cria transições suaves entre duas ou mais cores. Pode ser aplicado como fundo de elementos, botões, textos e muito mais (usando background-image).
linear-gradient() A transição de cores acontece em linha reta. A direção pode ser definida com to right, to left, to top, to bottom ou em graus.
radial-gradient() A transição de cores acontece a partir de um ponto central. Pode-se definir o ponto central e a forma (circle ou ellipse).
conic-gradient() A transição de cores acontece em volta de um ponto central, criando um efeito de "rotação".
múltiplas cores É possível colocar várias cores, separadas por vírgula, para criar efeitos mais complexos.
Propriedades Text Shadow e Box Shadow Descrição
text-shadow Adiciona sombra ao texto. Valores, na ordem: deslocamento horizontal, deslocamento vertical, desfoque e cor da sombra. Ex: text-shadow: 2px 2px 5px rgba(0, 0, 0, 0.5);
box-shadow Adiciona sombra à caixa do elemento. Valores, na ordem: deslocamento horizontal, deslocamento vertical, desfoque, raio de espalhamento e cor da sombra.
Efeito de Texto Descrição
white-space Define como o texto trata quebras de linha e espaços em branco.
white-space: normal; (Padrão) O texto quebra automaticamente em linhas e vários espaços em branco viram um só.
white-space: nowrap; O texto não quebra linha, ficando em uma única linha, e vários espaços em branco viram um só.
text-overflow Define o que acontece com o texto que ultrapassa os limites do elemento.
text-overflow: clip; (Padrão) O texto que passa do limite é cortado, sem indicação de que há mais conteúdo.
text-overflow: ellipsis; O texto que passa do limite é cortado e substituído por reticências (...), indicando que há mais conteúdo.
obs: ellipsis Para as reticências aparecerem, o elemento também precisa de white-space: nowrap; e overflow: hidden;
Media Queries Descrição
@media Técnica usada para aplicar estilos diferentes de acordo com o tamanho da tela ou do dispositivo.
max-width Aplica os estilos quando a largura da tela é menor ou igual ao valor informado.
min-width Aplica os estilos quando a largura da tela é maior ou igual ao valor informado.
and, not, only Combinam ou restringem condições. Ex: @media only screen and (max-width: 600px). Para "ou", usa-se a vírgula entre as condições.
até 600px Smartphones.
a partir de 600px Dispositivos um pouco maiores, mas ainda pequenos (tablets pequenos e smartphones largos).
a partir de 768px Dispositivos médios (tablets deitados).
a partir de 992px Dispositivos largos (laptops e desktops).
a partir de 1200px Telas super largas (laptops e desktops maiores e até TVs).
Flexbox (Contêiner) Descrição
flexbox Modelo de layout que distribui o espaço entre os itens de um contêiner e os alinha de forma eficiente, mesmo quando o tamanho deles é desconhecido ou muda.
display: flex; Transforma o elemento em um contêiner flexível.
flex-direction Define a direção dos itens: row, row-reverse, column ou column-reverse.
justify-content Alinha os itens no eixo principal (horizontal com row, vertical com column): flex-start, flex-end, center, space-between, space-around ou space-evenly.
align-items Alinha os itens no eixo cruzado (vertical com row, horizontal com column): flex-start, flex-end, center, baseline ou stretch.
flex-wrap Define se os itens quebram para a próxima linha: nowrap, wrap ou wrap-reverse.
flex-flow Junta flex-direction e flex-wrap em uma única propriedade.
Flexbox (Itens) Descrição
order Define a ordem dos itens (o padrão é 0).
flex-grow Define quanto o item pode crescer em relação aos outros.
flex-shrink Define quanto o item pode encolher em relação aos outros.
flex-basis Define o tamanho inicial do item antes de distribuir o espaço que sobra.
obs: box-sizing: border-box; Inclui o padding e a borda no tamanho total do elemento, facilitando o controle do layout.
