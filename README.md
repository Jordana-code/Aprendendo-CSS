# Aprendendo CSS

Este repositório contém uma página web interativa e estilizada desenvolvida para servir como um **guia prático de estudos de CSS**. O projeto foi estruturado visualmente com o tema de um "caderno de anotações" digital, reunindo conceitos fundamentais, sintaxes e tabelas de consulta rápida para o aprendizado de Folhas de Estilo em Cascata (CSS).

---

## Acesso ao Projeto

Você pode acessar o site publicado através do link:
👉 [Aprendendo CSS - GitHub Pages](https://jordana-code.github.io/Aprendendo-CSS/)

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo da página.
* **CSS3:** Estilização avançada com foco em design personalizado, tipografia e layout responsivo.
* **Google Fonts:** Utilização da fonte *Lora* para compor a identidade visual baseada em tipografia clássica de leitura.

---

## Funcionalidades e Características Visuais

* **Design Temático de Caderno:** Estilização personalizada com margens destacadas, bordas duplas imitando capas e blocos de conteúdo organizados como fichas de estudo.
* **Tabelas de Referência Completa:** Dezenas de tabelas organizadas por categorias cobrindo desde seletores e propriedades básicas até layouts avançados.
* **Tipografia Elegante:** Uso de fontes serifadas com suporte a recuos e espaçamentos personalizados.

## Conteúdo Abordado na Página

O guia está dividido em seções didáticas que cobrem os seguintes tópicos:

1. **Modos de Aplicação do CSS:**
   * *Inline* (diretamente na tag HTML)
   * *Internal* (na tag `<style>` no cabeçalho)
   * *External* (em arquivo `.css` separado)
2. **Seletores CSS:**
   * Elemento, Classe, ID e Seletor Universal.
3. **Guia de Propriedades e Conceitos (Tabelas de Consulta):**
   * Cores (`color`)
   * Fundos (`background` e variações)
   * Bordas e Arredondamento (`border`, `border-radius`)
   * Espaçamentos (`margin` e `padding`)
   * Dimensões e Alinhamentos (`width`, `height`, `text-align`)
   * Tipografia Avançada (`font-family`, `line-height`, `letter-spacing`)
   * Estilização de Links interativos (`a:link`, `a:hover`, `a:active`)
   * Modelos de Exibição (`display: block`, `inline`, `flex`, `none`)
   * Posicionamento (`position: relative`, `absolute`, `fixed`, `sticky`)
   * Controle de Transbordamento (`overflow`)
   * Elementos Flutuantes (`float`)
   * Opacidade e Efeitos Visuais (`opacity`, Sombras, Gradientes)
   * Especificidade CSS e a Regra `!important`
   * Design Responsivo com **Media Queries**
   * Layouts Modernos com **Flexbox** (Contêineres e Itens)
